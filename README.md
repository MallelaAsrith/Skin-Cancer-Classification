Skin Cancer Classification Using Transfer Learning

Project Overview

This project focuses on classifying skin lesion images into seven different categories using Deep Learning and Transfer Learning.

The project uses a pre-trained MobileNetV2 model to extract image features and classify skin lesions based on the HAM10000 dataset.

Objectives

- Develop a skin lesion image classification model.
- Apply Transfer Learning using MobileNetV2.
- Classify images into seven skin-condition categories.
- Evaluate model performance using appropriate evaluation metrics.

Dataset

Dataset: HAM10000 (Human Against Machine with 10000 training images)

- Total images: 10,015
- Number of classes: 7
- Metadata file: "HAM10000_metadata.csv"
- Dataset source: "Kaggle – Skin Cancer MNIST HAM10000" (https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000)

Classification Categories

Label| Category
akiec| Actinic keratoses / intraepithelial carcinoma
bcc| Basal cell carcinoma
bkl| Benign keratosis-like lesions
df| Dermatofibroma
mel| Melanoma
nv| Melanocytic nevi
vasc| Vascular lesions

Model Architecture

MobileNetV2 – Transfer Learning

The project uses MobileNetV2, a pre-trained convolutional neural network, as the feature extraction backbone.

The workflow includes:

1. Image loading and preprocessing
2. Dataset preparation
3. Loading the pre-trained MobileNetV2 model
4. Transfer learning and classification
5. Model training and validation
6. Performance evaluation
7. Skin lesion image prediction

Project Workflow

HAM10000 Dataset → Image Preprocessing → MobileNetV2 → Classification Layer → Model Training → Evaluation → Prediction
